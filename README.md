## Skorpion Extension
Skorpion syntax highlighting extension for Visual Studio Code

Adding:
- Syntax highlighting in Skorpion's files (`.sk`, `.spc`)
- Skorpion's files (`.sk`, `.spc`) icons

## Version
Corresponds to Skorpion version `2026.10.b01`.
